New file: scripts/cloudlab/run_tendermint_static.sh (gitignored)

A static-timeout, no-learning duplicate of run_tendermint.sh. It runs CometBFT in normal mode (learning agent never started) but injects the same fault curriculum (failure_spec fault injection isn't mode-gated), so it's a directly comparable baseline against the learning runs.

New flags:
- --timeout <ms> — fixed timeout applied to all three consensus timers (propose/prevote/precommit). Required.
- --timeout-propose/--timeout-prevote/--timeout-precommit <ms> — optional per-timer overrides (each defaults to --timeout).

Example:
scripts/cloudlab/run_tendermint_static.sh ~/.ssh/key --timeout 900 -t 10800 --log

How it works: the timeout values are validated locally, passed through the SSH call as positional args $12–$14, and on the remote the script rewrites the [consensus] timeout_propose/prevote/precommit keys in the extracted master config.toml before apply_master_config propagates them to every node. Only the run-root copy is touched — the tracked config/tendermint/config.toml is never modified, so no config duplication was needed. I verified the sed leaves the *_delta keys intact.
