# results/

The finalized experiment runs and the tables built from them.

| path                            | contents                                                                         |
|---------------------------------|----------------------------------------------------------------------------------|
| `RESULTS.md`                    | the tables, generated by `results_md.py` (do not edit by hand)                   |
| `<protocol>/<run>/`             | the main table: one run per configuration, 26 per protocol, each with `row.json` |
| `studies/pbft/<study>/<run>/`   | the PBFT studies E1-E6 (dense, fibonacci, sparse, local, nohold, window)         |
| `studies/pbft/*/calibration/`   | the calibration cells behind E3's oracles and E5's simulator fit                 |
| `judge.py`                      | the client judge: defines the score R per phase from a run's client output       |
| `scoring.py`                    | per-run scores and the aligned tables (`results_cache.json`, not tracked)        |
| `plot.py`                       | the per-protocol plots                                                           |

## Regenerating the tables

    python3 results/results_md.py --write

The first run scores every run directory (a few minutes) and caches the scores by run name.

## Rerunning a row

Each run directory holds what the run used: `run.env` (the exact harness command as `command=`, the frozen code it ran
under as `freeze_name`/`code_hash`, the prior as `prior_path`/`prior_md5`), `failure_spec.xml` and the configs.

- Replace the command's `--output-dir` and targets file with your own (five CloudLab machines set up by
  `scripts/cloudlab/setup.sh`; the run's `cloudlab_ssh_targets.txt` shows the format).
- A row's prior is in `learning_agent/pretrained_models/` (`INSTALLED.txt` lists which freeze each came from; the study
  priors are in `ps_<study>/`, the E5 simulator constants in `ps_e5/pbft_sim_e5_constants.json`). Every prior records the
  code hash it was trained under, so run with `ALLOW_UNFROZEN=1`: the harness otherwise refuses a tree or prior that
  differs from `FREEZE`.
- Scheduled PBFT and SBFT runs (oracles, calibration cells) take their schedule from the `SCHEDULE_FILE_REL` environment
  variable, which is not in `command=`: the oracle is `learning_agent/config/schedule_<protocol>.csv`, a calibration cell
  `learning_agent/config/cal_pbft_T<T>.csv` (or `sbcal_T<T>_W<W>.csv`), a prefix cell or study oracle
  `learning_agent/pretrained_models/schedules/<name>.csv` (the run name says which).
- Two study specs moved after their runs; `run.env` still names the old path:

| path in `run.env`                                                    | now                                                            |
|----------------------------------------------------------------------|----------------------------------------------------------------|
| `scripts/cloudlab/tmp/cal/restart/studies/e3/failure_spec_e3_r1.xml` | `results/studies/pbft/sparse/failure_spec_e3_r1.xml`           |
| `scripts/cloudlab/tmp/cal/blindall/pbft/blind_nohold1019.xml`        | `results/studies/pbft/nohold/calibration/blind_nohold1019.xml` |

Score a rerun with `python3 results/judge.py <run_dir>`.
